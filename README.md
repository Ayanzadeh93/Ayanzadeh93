### 🔬 Research Pipeline

<!-- ─── CUSTOM PIPELINE DIAGRAM (custom SVG, hand-designed for your work) ──── -->
<p align="center">
  <img src="./assets/research-pipeline.svg" alt="research-pipeline" width="100%"/>
</p>

> **Perception** extracts rooms, doors, and objects from raw floor plans using VLMs and YOLO-based detectors. **Representation** turns that into a navigable spatial graph plus a retrieval store. **Reasoning** uses agentic RAG to plan routes and verify them against hallucination. The output is a natural-language route a blind or low-vision user can actually follow.

### 🚀 Active Projects

<table>
<tr>
<td width="50%" valign="top">

#### 🗺️ Floorplan2Guide
LLM-guided floor plan parsing for indoor BLV navigation.
- **Venue:** IEEE Big Data 2025 · [arXiv:2512.12177](https://arxiv.org/abs/2512.12177)
- **Follow-on:** *LLM-Guided Agentic Floor Plan Parsing* — **CVPR 2026**
- **Stack:** `VLMs` `NetworkX` `LangChain`
- Decomposes floorplan understanding into agent sub-tasks (rooms, doors, adjacency) for grounded path queries.

</td>
<td width="50%" valign="top">

#### 💬 AidGPT
PhD thesis — conversational assistive agent for BLV users.
- **Related:** *On-Device Depth-Aware Multimodal Workload* — **IISWC 2026**
- **Stack:** `PyTorch` `Multimodal LLMs` `Speech`
- Real-time multimodal dialogue grounded in physical environment context, characterized for on-device deployment.

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 🔭 InVLM / AgenticRAG
Parameter-efficient VLM adaptation + multi-agent RAG for navigation instructions.
- **Stack:** `PEFT` `Qwen2-VL` `LangGraph` `🤗 Transformers`
- Specialist agents (planner, verifier, instructor) coordinate to suppress hallucination in safety-critical routing.
- **Project page:** [Indoor Navigation](https://www.ayanzadeh.com/projects/indoor-navigation.html)

</td>
<td width="50%" valign="top">

#### 🔥 WildfireVLM
AI-powered early wildfire analysis from satellite imagery.
- **Venue:** IGARSS 2026 · [arXiv:2602.13305](https://arxiv.org/abs/2602.13305)
- **Related:** *Modular Mechanisms for Auditable Wildfire Spread* — [arXiv:2609.17763](https://arxiv.org/abs/2609.17763)
